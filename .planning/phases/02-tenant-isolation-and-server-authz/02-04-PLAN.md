## Phase Goal

**As a** signed-in employee of Company A, **I want to** request and update leave using my signed-in session, **so that** Company B cannot read or change our people, requests, balances, calendars, notifications, or audit, and someone holding only the public API key cannot operate without a tenant session.

<objective>
Move remaining dashboard, calendar, and policy reads onto session-gated BFF routes and stop the browser anon IDatabaseService as the domain path, including password-excluding user selects.

Purpose: After 02-06 REVOKE, the UI must already fetch through the BFF or dashboards go empty. TENANT-04 read transport; RLS enforcement is 02-06.
Output: GET balances/notifications/policies/calendar/manager-stats; hook and calendar fetch swaps; provider default stop; UserRepository selects without password.
</objective>
