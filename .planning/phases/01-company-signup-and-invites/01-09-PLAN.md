accept_invite_with_employee(
  p_invite_id uuid,
  p_email TEXT,
  p_password TEXT,
  p_first_name TEXT,
  p_last_name TEXT,
  p_company_id uuid
) RETURNS users
LANGUAGE plpgsql (not STRICT). p_password nullable.

Body in one transaction: INSERT users (email p_email, password p_password, first_name, last_name, company_id p_company_id, role employee, department Unassigned, team Unassigned) RETURNING * INTO v_user; UPDATE company_invites SET status = accepted, accepted_at = now() WHERE id = p_invite_id AND status = pending; IF NOT FOUND THEN RAISE EXCEPTION invite_not_pending; END IF; RETURN v_user.

GRANT EXECUTE ON FUNCTION accept_invite_with_employee(uuid, TEXT, TEXT, TEXT, TEXT, uuid) TO anon, authenticated, service_role.

buildAcceptInviteWithEmployeeArgs input: inviteId, email, passwordHash: string | null, firstName, lastName, companyId
Returns object with keys p_invite_id, p_email, p_password, p_first_name, p_last_name, p_company_id. Always include p_password even when null (same as buildCreateCompanyWithOwnerArgs).

EMAIL_EXISTS_ERROR from invite-auth.ts. Credentials accept: keep global email 409 before RPC; on RPC unique_violation or code 23505 return 409 EMAIL_EXISTS_ERROR; map invite_not_pending to 404 invalid_or_expired.

ACCOUNT_EXISTS_PATH = /auth/error?error=AccountExists (export next to INVITE_REQUIRED_PATH). decideGoogleSignIn return type unchanged.

auth.ts pendingInvite other-company member: clearPendingAuthCookies then return ACCOUNT_EXISTS_PATH (not INVITE_REQUIRED_PATH). New Google user: supabase.rpc accept_invite_with_employee with passwordHash null instead of insert then update. On 23505: clear cookies, ACCOUNT_EXISTS_PATH. Catch that previously mapped accept failure to InviteRequired after a live insert must not remain: RPC failure rolls back.

Error page AccountExists: title An account with this email already exists. description Sign in, or ask your admin for an invite. action Sign in → router.push /auth/signin. Keep InviteRequired → /auth/signup. Reuse existing error-card chrome; do not invent a new page.
